# yt-dlp GUI — 使い方ガイド

YouTube をはじめとする様々なサイトの動画・音声を、  
かんたんな操作でダウンロードできるソフトです。

## 動作環境

- **OS**: Windows 10 / 11（64bit）
- **インストール不要**: Python・FFmpeg など追加ソフトのインストールは必要ありません
- **ネット接続**: ダウンロード時にインターネット接続が必要です

> サムネイルプレビュー機能を使用するには Pillow が必要です。  
> `pip install Pillow` でインストールしてください。

---

## 起動方法

`ytdlp_gui.exe` をダブルクリックしてください。それだけです。

> ウイルス対策ソフトが警告を出す場合がありますが、誤検知です。  
> 「許可する」または「実行する」を選んでください。

## 基本的な使い方

**① URLを貼り付ける**

画面左上の入力欄にダウンロードしたい動画のURLを貼り付けます。  
URLが入力されると青いバッジで件数が表示されます。  
URLは `Ctrl+V` で貼り付けるか、「クリップボードから貼り付け」ボタンでも追加できます。

**② 保存先を選ぶ**

「保存先」欄の右側にある「参照…」ボタンから保存先フォルダを選んでください。  
前回使ったフォルダは自動で記憶されます。

**③ ダウンロード開始**

右パネル上部の「▶ ダウンロード開始」ボタンを押すと開始します。  
全体進捗バーの横にダウンロード速度と残り時間がリアルタイム表示されます。

途中でやめたい場合は「■ 停止」ボタンを押してください。  
エラーが出たURLは「↺ 再試行」ボタンで再実行できます。

**④ 完了後にファイルを確認する**

完了したタスクをダブルクリックすると、保存先フォルダをエクスプローラーで開きます。  
Windows ではダウンロードしたファイルが選択状態で表示されます。

## 主な機能

### ダウンロードモード切り替え

「ダウンロードモード」で **動画** か **音声のみ** を選べます。

- **動画**: mp4 / mkv / webm などの形式、画質（最高品質〜360p）を選択可能
- **音声のみ**: mp3 / wav / flac / m4a などに変換して保存

### キュー並び替え

ダウンロード待機中のタスクは「↑ 上へ」「↓ 下へ」ボタンまたはマウスのドラッグで順序を変更できます。ダウンロード中・完了済みのタスクは移動できません。

### 動画情報の事前確認

キュータブの「ℹ 情報確認」ボタンで、入力欄の最初のURLについてタイトル・長さ・再生数・利用可能なフォーマット一覧を表示します。Pillow がインストールされている場合はサムネイルも表示されます。

### リアルタイム速度グラフ

「📈 速度グラフ」タブで過去60秒分のダウンロード速度を折れ線グラフとして確認できます。

### スケジュール実行

「⏰ スケジュール実行」セクションで時刻（HH:MM形式）を指定すると、その時刻に自動でダウンロードを開始します。残り時間もリアルタイムで表示されます。

### ファイル名の変更

「✏ ファイル名変更」欄に名前を入力すると、そのファイル名で保存できます。単体動画のダウンロード時のみ有効です。

### ダウンロード済みをスキップ

「オプション」の「ダウンロード済みをスキップ」をオンにすると、同名ファイルが存在する場合はスキップします。

### 完了後アクション

「高度な設定」の「完了後アクション」で、全ダウンロード完了後の動作を設定できます。

- **何もしない**: そのまま待機します
- **フォルダを開く**: 保存先フォルダを自動で開きます
- **シャットダウン**: 確認後、30秒後にPCをシャットダウンします

### 設定プリセット

「💾 設定プリセット」セクションで、現在の設定を名前をつけて保存・呼び出しができます。

### ログの書き出し

「📝 ログ」タブの「💾 ログを保存」ボタンでログをテキストファイルに保存できます。

### プレイリスト一括ダウンロード

「オプション」の「プレイリスト全体をDL」をオンにしてプレイリストURLを貼り付けると、収録動画をまとめてダウンロードします。

### 字幕のダウンロード

「オプション」の「字幕をDL・埋め込み」または「自動生成字幕もDL」をオンにすると、動画ファイルに字幕を埋め込んで保存できます。

### 範囲を指定してダウンロード

「オプション」の「範囲ダウンロード」に開始・終了時間を入力すると、動画の一部だけを切り出せます。

例：`開始 00:01:30`　`終了 00:03:00`

## うまくいかないときは

**ダウンロードが失敗する・エラーが出る**

「オプション」の「エラーを無視して続行」がオンになっているか確認してください。yt-dlp は頻繁に更新されるため、古いバージョンでは動作しなくなるサイトが増えることがあります。

**指定した形式（mp3 など）に変換されない**

「ダウンロードモード」が **音声のみ** になっているか確認してください。

**メンバー限定・年齢制限の動画をダウンロードしたい**

1. ブラウザ拡張機能「[Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)」をインストール
2. 対象サイトにログインした状態で `cookies.txt` を書き出す
3. 「高度な設定」の「Cookie ファイル」欄に指定する

**YouTube でレート制限エラーが出る**

時間をおいてから再試行してください。「高度な設定」の「帯域制限」に `2M` などを設定すると再発を防ぎやすくなります。

**ウイルス対策ソフトが反応する**

PyInstaller 製 EXE ファイルは誤検知されることがあります。「許可」「ホワイトリストに追加」で回避してください。
