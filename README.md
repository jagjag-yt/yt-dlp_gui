# yt-dlp GUI — 使い方ガイド

YouTube をはじめとする様々なサイトの動画・音声を、  
かんたんな操作でダウンロードできるソフトです。

## 動作環境

- **OS**: Windows 10 / 11（64bit）
- **インストール不要**: Python・FFmpeg など追加ソフトのインストールは必要ありません
- **ネット接続**: ダウンロード時にインターネット接続が必要です

> 動画情報確認でのサムネイル表示は、Python から直接実行し Pillow（`pip install Pillow`）を入れた場合のみ有効です。配布版（EXE）では表示されません。

---

## 起動方法

`ytdlp_gui.exe` をダブルクリックしてください。それだけです。

> ウイルス対策ソフトが警告を出す場合がありますが、誤検知です。  
> 「許可する」または「実行する」を選んでください。

## 基本的な使い方

**① URLを貼り付ける**

左パネル「基本」タブの「URL入力」欄に、ダウンロードしたい動画のURLを貼り付けます（1行に1つ、複数可）。  
`Ctrl+V` のほか、「貼り付けで追加」「クリップボードから貼り付け」ボタンでも追加できます。URLの件数は欄の下に表示されます。

**② モードと保存先を選ぶ**

「ダウンロードモード」で **動画** か **音声のみ** を選び、「保存先」の「参照…」で保存フォルダを選びます。  
最近使ったフォルダは保存先の下に表示され、クリックで切り替えられます。

**③ ダウンロード開始**

右パネル上部の「▶ ダウンロード開始」を押すと開始します。  
ステータスカードに全体の進捗・合計速度・残り時間が表示され、キューの各行にも状態と進捗が表示されます。

「■ 停止」を押すと進行中の項目は「一時停止」になります。「↻ 再試行」で、エラー・一時停止の項目をまとめて再開できます。  
エラーになった行の「再試行」リンクを押すと、その1件だけを再試行します。

**④ 完了後にファイルを確認する**

完了した行をダブルクリックすると、保存先フォルダをエクスプローラーで開きます（Windows ではファイルが選択された状態で開きます）。

## 主な機能

### ダウンロードモード

- **動画**: 形式（自動（最高画質）/ mp4 / mkv / webm）と画質（最高品質〜360p）を選択
- **音声のみ**: mp3 / m4a / wav / flac に変換して保存

> サムネイル埋め込みは mp4 / mkv / mp3 / m4a / flac で有効です（webm・wav は埋め込みに対応していないため、埋め込みなしで保存します）。

### 基本タブと詳細設定タブ

よく使う設定（URL・モード・保存先・プレイリスト・サムネイル・字幕）は「基本」タブに、それ以外は「詳細設定」タブにまとめています。

### キューの操作

キューの行を右クリックすると、再試行・動画情報の確認・保存先フォルダを開く・上下移動（待機中のみ）・全選択・削除ができます。  
`Ctrl` を押しながらクリックすると複数選択できます。

### 動画情報の事前確認

キューの行の右クリックメニュー「動画情報を確認」で、タイトル・投稿者・長さ・再生数・利用可能なフォーマット一覧を表示します。

### 速度グラフ

右パネルの「速度グラフ」タブで、現在の合計速度と直近の速度の推移を確認できます。

### yt-dlp の更新

画面下のステータスバーの「更新確認」から、yt-dlp の現在／最新バージョンを確認して更新できます。サイト側の仕様変更でダウンロードできなくなったときは、まず更新を試してください。

### 暗号化保存

「詳細設定」→「暗号化保存」をオンにしてパスワードを入力すると、ダウンロード後のファイルを AES-256 で暗号化して `.enc` として保存します（元のファイルは削除されます）。  
復号は同じ欄の「.enc ファイルを復号…」から行えます。パスワードは保存されないので、忘れないようにしてください。

### yt-dlp 非対応サイトのダウンロード

yt-dlp が対応していないサイトのURLでも、ページの中に動画が埋め込まれていれば自動で探してダウンロードします。特別な操作は不要で、普段どおりURLを貼り付けて開始するだけです。

- ログに「ページ内の動画を探します」「ページ内で動画を見つけました」と表示されます
- ページに動画が複数ある場合は、最も高画質と思われるもの（ストリーミング形式 → 動画ファイルの順）を1つダウンロードします
- ログインが必要なページは、「Cookie ファイル」を設定すると探せる場合があります
- ページを開いたあとに動画を読み込むサイト（再生ボタンを押すまで動画の場所が出てこないものなど）や、DRM で保護された動画はダウンロードできません
- この機能を使いたくない場合は「詳細設定」→「非対応サイト」をオフにしてください

### ファイル名の変更

「詳細設定」→「ファイル名変更」に名前を入力すると、その名前で保存します。URLが1件でプレイリストDLがオフのときのみ有効です。

### ダウンロード済みをスキップ

「詳細設定」の「ダウンロード済みをスキップ」をオンにすると、同名ファイルがある場合は上書きしません。

### 完了後アクション

「詳細設定」→「高度な設定」の「完了後」で、すべてのダウンロードが終わったあとの動作を選べます。

- **何もしない** / **フォルダを開く**
- **PCをスリープ**: 確認後にスリープします
- **PCをシャットダウン**: 確認後、30秒後にシャットダウンします（取り消し: コマンドプロンプトで `shutdown /a`）

### 設定プリセット

「詳細設定」→「設定プリセット」で、現在の設定に名前を付けて保存・読込・削除できます。

### スケジュール実行

「詳細設定」→「スケジュール実行」をオンにして時刻（HH:MM）を入力すると、その時刻に自動でダウンロードを開始します。

### ログの保存

「ログ」タブの「保存」ボタンでログをテキストファイルに書き出せます。

### プレイリスト一括ダウンロード

「プレイリスト全体をDL」をオンにしてプレイリストのURLを貼り付けると、収録動画をまとめてダウンロードします。

### 字幕のダウンロード

「字幕をDL・埋め込み」（基本タブ）をオンにすると、日本語・英語の字幕を動画に埋め込みます。「自動生成字幕もDL」（詳細設定タブ）で自動生成字幕も対象にできます。

### 範囲を指定してダウンロード

「詳細設定」→「範囲ダウンロード」に開始・終了時間を入力すると、動画の一部だけを切り出せます。

例：`開始 00:01:30`　`終了 00:03:00`

## うまくいかないときは

**ダウンロードが失敗する・エラーが出る**

「詳細設定」の「エラーを無視して続行」がオンになっているか確認してください。yt-dlp は頻繁に更新されるため、古いバージョンでは動作しなくなるサイトが増えることがあります。ステータスバーの「更新確認」から更新してください。

**指定した形式（mp3 など）に変換されない**

「ダウンロードモード」が **音声のみ** になっているか確認してください。

**メンバー限定・年齢制限の動画をダウンロードしたい**

1. ブラウザ拡張機能「[Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)」をインストール
2. 対象サイトにログインした状態で `cookies.txt` を書き出す
3. 「詳細設定」→「高度な設定」の Cookie ファイル欄に指定する

**YouTube でレート制限エラーが出る**

時間をおいてから再試行してください。「詳細設定」→「高度な設定」の「帯域制限」に `2M` などを設定すると再発を防ぎやすくなります。

**ウイルス対策ソフトが反応する**

PyInstaller 製 EXE ファイルは誤検知されることがあります。「許可」「ホワイトリストに追加」で回避してください。
